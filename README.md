# Lernano

Lern-App für Mary (NMG, Deutsch, Englisch, Französisch, Mathe).

- Öffnen: die GitHub-Pages-Adresse in Safari öffnen → Teilen → «Zum Home-Bildschirm».
- Neue Themen: In der Claude-Version unter «Für Eltern» erstellen, Code an Mary schicken, in Lernano bei «Neu» einfügen.
- Fortschritt sichern: Startseite → «Fortschritt sichern».
- Neue Version hochladen: Dateien ersetzen und in `sw.js` die Nummer bei `CACHE` erhöhen (z. B. `lernano-v2`).
